## About Me

I'm a university student and self-described code addict. I got my start building Minecraft plugins and clients in Java — learning how game engines, Gradle build systems, and modding APIs work by just diving in. From there I moved into Python automation, Discord bots, and now I'm most excited about what's happening in agentic AI.

My current focus is **Stadium Copilot AI**, and my longer-term dream is to build a search engine from scratch. I care about making projects feel good to use — clean interfaces, sensible defaults, nothing unnecessary.

- **Preference:** Python projects
- **Currently learning:** Agentic AI and C++
- **Aim:** WhiteHat security
- **Dream project:** A search engine

## Featured Projects

### [RaptorClient-beta](https://github.com/Noobplayer77777/RaptorClient-beta)
> A custom Minecraft client for 2b2t, built in Java with Gradle.

A full client mod targeting the anarchist Minecraft server 2b2t. Implements custom rendering, access transformers, a custom font renderer, and gameplay modules. Built with Forge, Gradle, and GitHub Actions for CI. Shows an ability to work inside a large existing codebase and extend it with custom systems — non-trivial Java engineering for a game that doesn't make modding easy.

`Java` · `Gradle` · `Forge` · `GitHub Actions`

---

### [NOOB-BOT](https://github.com/Noobplayer77777/NOOB-BOT)
> A Discord moderation bot with a configurable rule system.

A Python Discord bot with a full command set: mute, kick, ban, unban, clear, vote, invite, and customisable server rules via `rules.txt`. Clean command prefix architecture (`!`). A practical tool that demonstrates real-world Python scripting, bot API usage, and community tooling.

`Python` · `discord.py` · `Node.js`

---

### [Custom-plugin](https://github.com/Noobplayer77777/Custom-plugin)
> A first-attempt Bukkit/Spigot Minecraft server plugin in Java.

A Java plugin built from scratch with welcome messages and custom commands — notable because it's documented honestly as a first attempt, with a release shipped anyway. Has a star. Shows initiative and willingness to publish work in progress.

`Java` · `Bukkit/Spigot`

---

### [Wooden-armor](https://github.com/Noobplayer77777/Wooden-armor)
> A custom Minecraft item mod adding wooden armour to the game.

Maven-based Java project, structured with proper `src/main` layout and a versioned release. Another mod that adds a new item tier to Minecraft, demonstrating Maven build tooling and Minecraft API knowledge alongside the Gradle-based projects.

`Java` · `Maven` · `Bukkit`
